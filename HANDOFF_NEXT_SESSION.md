# 🏆 СЕССИОННЫЙ ПЕРЕХОД: Защита от повторной записи (Anti-Abuse) и Чистый мобильный интерфейс лендинга

## 🎯 1. Цель и фокус сессии
1. **Anti-Abuse движок проверки прав и дедупликации пробных занятий:**
   - Лимит: **1 бесплатное пробное занятие на одного ребёнка / семью**.
   - Нормализация телефона в канонический формат `7XXXXXXXXXX` и нормализация ФИО ребенка (регистр, лишние пробелы, замена `ё` на `е`).
   - Сквозная проверка по трем коллекциям Firestore:
     - `requests` (активные заявки по телефону и ФИО со статусами `new`, `pending`, `approved`, `confirmed`, `attended`, `completed`, `enrolled`).
     - `trials` (история визитов на пробные тренировки).
     - `users` (уже зарегистрированные спортсмены школы).
   - Информативные экраны статуса с блокировкой повторных отправок в `TrialModal.tsx` и `SmartEnrollmentWizard.tsx`.
2. **Чистый мобильный интерфейс лендинга для авторизованных пользователей (Решение Варианта 2):**
   - Устранена навязчивая фиксированная нижняя плашка на мобильных устройствах для всех авторизованных пользователей (`user !== null`).
   - Родители, сотрудники, тренеры и разработчики просматривают весь лендинг с чистым обзором экрана без напряжения и визуального шума.
   - Доступ в Личный кабинет / панель управления всегда под рукой через верхнюю закрепленную шапку сайта (круглая иконка профиля с аватаром / первой буквой имени) и бургер-меню.
   - Для неавторизованных гостей (`!user`) нижняя конверсионная панель «Записаться на пробное (0 ₽)» сохранена.
3. **Сборка, E2E-тестирование и публикация в продакшн:**
   - Проверка сборки `npm run build` (Exit code: 0, 0 ошибок).
   - E2E Playwright валидация мобильного интерфейса (390x844) для гостя и авторизованного пользователя.
   - Актуализация графа знаний: `npx graphify update .`.
   - Деплой на Vercel и назначение основного алиаса **`https://sparta-sports-center.vercel.app`**.

## 📁 2. Внесенные изменения (по файлам)

### 1. `utils/trialEligibility.ts` (НОВЫЙ)
- Реализованы функции нормализации `normalizePhone` и `normalizeName`.
- Реализована асинхронная функция `checkTrialEligibility(params)`:
  - Проверяет коллекции Firestore `requests`, `trials`, `users`.
  - Возвращает `{ eligible: boolean, reason?: TrialIneligibilityReason, message?: string, existingRecord?: any }`.

### 2. `components/LandingPage.tsx`
- Нижняя мобильная плашка скрыта для авторизованных пользователей: `{!user && ( ... )}`.
- Отступ контента снизу динамически подстраивается: `user ? "pb-6 md:pb-0" : "pb-24 md:pb-0"`.
- Удалены неиспользуемые переменные и импорты (`LayoutDashboard`, `Clock`, `STAFF_ROLES`, `isStaff`, `hasRequestedTrial`, `hasEnrolledKids`).

### 3. `context/AuthContext.tsx`
- Добавлен real-time слушатель Firestore `requests` по номеру телефона родителя (`userProfile?.phone` / `user.phoneNumber`).
- Заявки без явного `groupId` также корректно распознаются как активные.

### 4. `components/TrialModal.tsx`
- Интегрирована валидация `checkTrialEligibility` перед отправкой заявки.
- Добавлено сохранение нормализованного поля `cleanPhone`.
- Разработана информативная карточка статуса при обнаружении ранее поданной заявки или зачисленного спортсмена.

### 5. `components/SmartEnrollmentWizard.tsx`
- Интегрирована проверка `checkTrialEligibility` перед регистрацией и созданием заявки.
- Добавлено сохранение поля `cleanPhone` в `trials` и `requests`.
- Отображение понятного статуса и вариантов перехода в Личный кабинет.
