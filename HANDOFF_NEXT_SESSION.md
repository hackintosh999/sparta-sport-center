   - Директор: `bugrova.k@bk.ru`

3. **Автоматическая настройка Vercel и деплой:**
   - Подключение к Vercel через CLI.
   - Установка 7 переменных окружения для SMTP Mail.ru в Production.
   - Сборка и успешный деплой кода на продакшен с привязкой домена `https://sparta-sports-center.vercel.app`.
   - Живой тест отправки письма на серверах Vercel (получен `HTTP 200 { success: true, sent: true }`).

## 📁 2. Внесенные изменения (по файлам)

### 1. `api/notify-lead.js` [НОВЫЙ]
- Серверная бессерверная функция (Serverless Function Vercel, ESM) на базе `nodemailer`.
- Содержит адаптивный HTML-шаблон в золотисто-черном брендовом стиле SPARTA: кликабельный телефон `tel:`, данные родителя и ребенка, возраст, филиал, группа, время Челябинска (UTC+5), кнопка перехода в CRM.
- Механизм отказоустойчивости с перебором отправителя для соблюдения строгих политик Mail.ru.

### 2. `services/leadNotificationService.ts` [НОВЫЙ]
- Единая точка диспетчеризации входящих лидов:
  - Запись системного уведомления в коллекцию `notifications` Firestore для ролей `admin` и `director`.
  - Отправка запроса на `/api/notify-lead`.

### 3. `utils/audioAlert.ts` [НОВЫЙ]
- Чистый генератор звукового оповещения (колокольчик 587Hz -> 880Hz) через браузерный `AudioContext` без внешних mp3-файлов.

### 4. `components/admin/AdminLayout.tsx` [ИЗМЕНЁН]
- Подключен real-time слушатель `onSnapshot` к коллекции `requests` со статусом `'new'`.
- При поступлении новой заявки проигрывается аудио-сигнал и отображается золотой интерактивный Toast с именем, телефоном и кнопкой перехода.

### 5. Точки захвата заявок на сайте [ИЗМЕНЕНЫ]:
- `components/TrialModal.tsx` — запись на пробное занятие.
- `components/SmartEnrollmentWizard.tsx` — пошаговый мастер подбора группы.
- `components/MembershipModal.tsx` — выбор и покупка абонемента.
- `components/ContactModal.tsx` — форма связи и вопросов.

### 6. Конфигурация и сервер:
- `vercel.json` — добавлен rewrite `/api/notify-lead` -> `/api/notify-lead.js`.
- `server.js` — локальный маршрут Express `POST /api/notify-lead` для работы во время локальной разработки (`npm run dev`).
- `package.json` — подключены зависимости `nodemailer` и `@types/nodemailer`.
