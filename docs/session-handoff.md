# 🏆 СЕССИОННЫЙ ПЕРЕХОД: Защита от повторной записи на пробное (Anti-Abuse) и динамическая мобильная панель

## 🎯 1. Цель и фокус сессии
1. **Динамическая нижняя панель на мобильном лендинге для авторизованных ролей:**
   - Для разработчика и сотрудников (`developer`, `dev`, `admin`, `director`, `coach`, `trainer`, `super`) статическая плашка «Записаться на пробное (0 ₽)» заменена на быструю кнопку **«В панель управления»** (переход в `/admin` или `/dashboard`).
   - Для родителей с активной заявкой отображается кнопка **«Заявка на рассмотрении»** (переход в `/dashboard?tab=requests`).
   - Для родителей с зачисленными детьми отображается кнопка **«Кабинет родителя»** (переход в `/dashboard?tab=family`).
   - Для новых гостей отображается «Записаться на пробное (0 ₽)».
   - Кнопка профиля рядом при наличии сессии сразу открывает Личный кабинет.
2. **Anti-Abuse движок проверки прав и дедупликации пробных занятий:**
   - Правило: **1 бесплатное пробное занятие на одного ребёнка / семью**.
   - Нормализация телефона в канонический 11-значный вид `7XXXXXXXXXX` и нормализация ФИО ребенка (регистр, пробелы, замена `ё` на `е`).
   - Сквозная проверка по трем коллекциям Firestore:
     - `requests` (активные заявки по телефону и ФИО со статусами `new`, `pending`, `approved`, `confirmed`, `attended`, `completed`, `enrolled`).
     - `trials` (история визитов на пробные тренировки).
     - `users` (уже зарегистрированные спортсмены школы).
3. **Информативные экраны отказа вместо спам-дублей:**
   - Интеграция в `TrialModal.tsx` и `SmartEnrollmentWizard.tsx`.
   - При повторной попытке форма блокирует запись и отображает карточку с подробным объяснением статуса, проверенными данными и прямым переходом в Личный кабинет либо чат с администратором.
4. **Сборка, тестирование и деплой на Vercel:**
   - Проверка сборки `npm run build` (Exit code: 0).
   - E2E проверка через Playwright на мобильном вьюпорте (390x844).
   - Актуализация графа знаний: `graphify update .`.
   - Деплой в Production и привязка к основному домену `https://sparta-sports-center.vercel.app`.

## 📁 2. Внесенные изменения (по файлам)

### 1. utils/trialEligibility.ts *(НОВЫЙ)*
- Реализованы функции `normalizePhone` и `normalizeName`.
- Реализована асинхронная функция `checkTrialEligibility(params)`:
  - Проверяет коллекции `requests`, `trials`, `users`.
  - Возвращает `{ eligible: boolean, reason?: TrialIneligibilityReason, message?: string, existingRecord?: any }`.

### 2. components/LandingPage.tsx
- Исправлен массив `STAFF_ROLES`: удален ошибочный `'parent'`, добавлены `'dev'`, `'super'`, `'trainer'`.
- Добавлены реактивные флаги `hasRequestedTrial` и `hasEnrolledKids`.
- Нижняя мобильная панель адаптирована под текущий статус пользователя (Панель управления / Заявка на рассмотрении / Кабинет родителя / Записаться на пробное).
- Кнопка профиля сразу переводит авторизованного пользователя в ЛК.

### 3. context/AuthContext.tsx
- Добавлен real-time слушатель Firestore `requests` по номеру телефона родителя (`userProfile?.phone` / `user.phoneNumber`).
- Заявки без явного `groupId` теперь также учитываются как активные.

### 4. components/TrialModal.tsx
- Интегрирована проверка `checkTrialEligibility` перед отправкой формы в Firestore.
- Добавлено сохранение поля `cleanPhone`.
- Разработана карточка отображения статуса для повторных заявок с кнопками перехода в ЛК и чат с администратором.

### 5. components/SmartEnrollmentWizard.tsx
- Интегрирована проверка `checkTrialEligibility` перед созданием пользователя, заявки и пробного визита.
- Добавлено сохранение поля `cleanPhone` в `trials` и `requests`.
- Разработан экран статуса с адаптивными кнопками перехода в ЛК и изменения данных.
